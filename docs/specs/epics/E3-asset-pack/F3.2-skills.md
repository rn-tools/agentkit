## S3.2.1 — Package and install the two skills

**State:** Closed (2026-11-20)

**Acceptance:**

- Contract: an `ArtifactSpec` with `skill=<name>` is skipped when the agent's
  `skills.disabled` names it; a value that is not a list of strings is a
  `SourceError`. The live files have no `allowed-tools`, so Codex gets
  byte-identical copies with no template (owner, 2026-11-20).

- Rendered Claude copies byte-match the live 2026-11-14 files (snapshots
  committed).

- Codex copies exist with front matter valid for Codex (name, description) and
  no `allowed-tools`.

- The user overlay can disable a skill per agent
  (`[codex] skills.disabled = ["sonar-cleanup"]`); a disabled skill previously
  installed is removed on apply.
