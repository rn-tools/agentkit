The shared guard library and per-agent dialect adapters, installed under the
share dir, registered through the owned Claude `hooks` key and a managed
`~/.codex/hooks.json`.

## Design

Scripts install under `$RNF_HOME/share/agentkit/` at the same paths the old tool
used:

- `_common/hooks/guard-core.sh`
- `claude/hooks/{pre-bash-guard,pre-write-protect,user-prompt-secret-guard,session-compact-context}.sh`
- `codex/hooks/{pre-bash-guard,pre-write-protect,user-prompt-secret-guard}.sh`

Port from
`rn_backup/agentkit/src/rn_forge/agentkit/assets/scripts/guard-core.sh` and
`agents/*/assets/hooks/*`, with their tests (`rn_backup/agentkit/tests/hooks/`).

**Fix:** hook command paths render from `$RNF_HOME` at apply time instead of the
hard-coded `$HOME/.rn-forge`. With `RNF_HOME` unset they render as the literal
`$HOME/.rn-forge/share/agentkit/...` (the form in today's files, so their bytes
and Codex's hook trust hashes do not change); with it set, as its absolute
value.

## S3.1.1 — Port the guard library, adapters and tests

**State:** Closed (2026-11-20)

**Acceptance:**

- Contract: a `Base.SHARE` spec's path is relative to the work dir and written
  relative to `$HOME`, so `RNF_HOME` must be under `HOME`, or apply exits 1
  (owner, 2026-11-20). `guard-core.sh` is a `COMMON` artifact, owned by no
  agent and installed whenever any agent is selected.

- The ported hook test suite passes for both dialects (Claude: exit 2 and reason
  on stderr; Codex: `{"decision":"block"}` on stdout, exit 0).

- Malformed hook input: bash and write guards block; the prompt guard warns and
  allows.

- Scripts install with mode 0755.

## S3.1.2 — Register the hooks for both agents

**State:** New · **Depends on:** S1.4.2

**Acceptance:**

- With `RNF_HOME` set to a temp dir, every rendered hook command path starts
  with that dir.
- With `RNF_HOME` unset, rendered `~/.codex/hooks.json` is byte-identical to the
  2026-11-14 live file (snapshot committed), so Codex hook trust is not
  invalidated.
- Claude registrations cover PreToolUse Bash, PreToolUse
  `Write|Edit|MultiEdit|NotebookEdit`, SessionStart compact, and
  UserPromptSubmit.
