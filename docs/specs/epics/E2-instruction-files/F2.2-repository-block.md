`apply --scope repo` writes the agentkit block into `<repo>/AGENTS.md` from the
`[repo]` overlay table, seeds `CLAUDE.md` as `@AGENTS.md` when absent, and
gitignores its derived files.

## Design

`[repo]` keys in v1:

- `worktree_root`: string, for example `../{repo}-wt/`; the `{repo}` placeholder
  expands to the repository directory name.
- `shared_checkout`: bool; renders "commit by explicit path, never `git add -A`,
  re-check HEAD before committing".
- `story_workflow`: string; one paragraph or a link.

Packaged defaults set none, so a repository with no overlay gets no block.

## S2.2.1 — AGENTS.md block from the repo overlay

**State:** Closed (2026-11-20)

**Acceptance:**

- With no `[repo]` keys set, apply writes no block and plans nothing for
  `AGENTS.md`.
- Contract: `rn_forge.agentkit.repository.render` holds the repository-scope
  artifacts, rendered at repo scope whatever `--agent` says. The block body is
  `## Agent workflow` followed by one bullet per set key, in the order
  worktrees, shared checkout, story workflow. An unknown `[repo]` key, or a
  value of the wrong type, is a `SourceError` naming the key (exit 1).
- With keys set, the block lands in `AGENTS.md`; a kiln block
  (`<!-- BEGIN rn-forge kiln -->` to its END) already in the file is
  byte-identical afterwards (fixture: a kiln-shaped `AGENTS.md`).
- Unsetting every key on a later apply removes the block and leaves the rest of
  the file byte-identical.
- `{repo}` in `worktree_root` renders as the repository directory name.

## S2.2.2 — CLAUDE.md seed

**State:** Closed (2026-11-20)

**Acceptance:**

- `CLAUDE.md` absent: created as exactly `@AGENTS.md\n`; recorded as seeded.
- `CLAUDE.md` present (any content): never read for drift, never rewritten,
  across two applies.

## S2.2.3 — gitignore block for derived files

**State:** New

**Acceptance:**

- `.gitignore` gains a `# BEGIN rn-forge agentkit` block ignoring
  `.rn-forge/agentkit/backups/` and `.rn-forge/agentkit/.staging/`;
  `state.json` is not ignored.
- An existing kiln `.gitignore` block is byte-identical afterwards.
