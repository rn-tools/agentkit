## S2.3.1 — Import and duplicate-heading checks

**State:** Closed (2026-11-21)

**Acceptance:**

- Repo scope: a `CLAUDE.md` without an `@AGENTS.md` line gives a warning naming
  the file.

- Both scopes: a Markdown heading in a body whose text equals a heading inside
  agentkit's block in the same file gives a warning naming the heading.

- An `AGENTS.md` that points the reader at `CLAUDE.md` as the canonical file
  (the old pointer seed: contains "Read `CLAUDE.md` now") gives a warning.

- Contract: the checks read `.claude/CLAUDE.md` and `.codex/AGENTS.md` at
  machine scope, `AGENTS.md` and `CLAUDE.md` at repo scope, whatever agents
  are selected. Finding codes `agentkit.claude-import-missing`,
  `agentkit.heading-duplicated` and `agentkit.agents-points-at-claude`, all
  warnings. Headings inside fenced code are ignored; a heading inside kiln's
  block counts as body.
