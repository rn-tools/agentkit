# S2.1.1 — Render the shared source to both blocks and the output style

Brief for
[S2.1.1](../F2.1-machine-instruction-blocks.md#s211-render-the-shared-source-to-both-blocks-and-the-output-style),
at the commit that adds this brief (parent `de02075`).

## Goal

Package the shared working rules and the concise output style. At machine scope,
render the rules into the agentkit block of `~/.claude/CLAUDE.md`, the rules
plus the style into the agentkit block of `~/.codex/AGENTS.md`, and write the
managed `~/.claude/output-styles/concise.md`. The text comes from the live files
on this machine as of 2026-11-20.

## Settled

- **Specs go in `src/rn_forge/agentkit/adapters/instructions.py` only.** That
  module exists, with empty `CLAUDE` and `CODEX` tuples. `adapters/claude.py`
  and `codex.py` already splice it in. S3.1.1 (`hooks.py`) and S3.2.1
  (`skills.py`) run in parallel, so do not edit `claude.py`, `codex.py`,
  `spec.py` or `__init__.py`.

- **`BLOCK = ManagedBlock("rn-forge agentkit", comment="<!--")`**, defined in
  `instructions.py`. Its markers are `<!-- BEGIN rn-forge agentkit -->` and
  `<!-- END rn-forge agentkit -->` (F2.1 Design).

- **Specs:**

    - `CLAUDE`:
        - `ArtifactSpec(".claude/CLAUDE.md", ArtifactKind.BLOCK, "instructions/rules.md", block=BLOCK)`,
          copied verbatim.
        - `ArtifactSpec(".claude/output-styles/concise.md", ArtifactKind.MANAGED, "instructions/concise.md.j2", template=True)`
    - `CODEX`:
        - `ArtifactSpec(".codex/AGENTS.md", ArtifactKind.BLOCK, "instructions/codex.md.j2", template=True, block=BLOCK)`

- **Assets** live under `src/rn_forge/agentkit/assets/instructions/`. The
  template engine's root is `assets/`, so includes are written
  `{% include "instructions/<file>" %}`.

    - `rules.md` is the concatenation, byte for byte, of:

        1. lines 1–13 of `~/.claude/CLAUDE.md`: the title and `## Bias to action`
           with its `dev-team-orchestration` bullet, through the blank line 13;
        1. lines 11–33 of `~/.codex/AGENTS.md`: `## Model routing and token economy`
           through the blank line 33;
        1. lines 14–39 of `~/.claude/CLAUDE.md`: `## Scope and simplicity` to the
           end of the file, including its final newline.

        Both sections go into shared rules (owner, 2026-11-19, F2.1 Design). Build
        the file with `sed -n` and `cat`, never by retyping. The live
        `~/.claude/CLAUDE.md` has no body-only lines.

    - `style.md`: `~/.claude/output-styles/concise.md` from line 6 to the end,
      which drops the front matter (lines 1–4) and the blank line 5. It is
      byte-identical to lines 61–123 of `~/.codex/AGENTS.md`; the reviewer
      checked with `cmp`.

    - `codex.md.j2` renders exactly `rules + "\n" + style`. That matches the live
      Codex file: rules, one blank line, then `# Output Style: Concise`.
      Commons' engine keeps trailing newlines, so the template's own final
      newline would add a byte. Write it so the render is exact, and let test 2
      pin it.

    - `concise.md.j2` renders exactly
      `"---\nname: Concise\ndescription: Minimal output, assume technical proficiency, tight context hygiene\n---\n\n" + style`.
      That is byte-identical to the live `~/.claude/output-styles/concise.md`.

- **mdformat does not touch these files.** `.mdformat.toml` excludes
  `src/rn_forge/agentkit/assets/**` and `tests/snapshots/**` (reviewer,
  2026-11-20), so `task format` keeps the live bytes. Do not edit
  `.mdformat.toml`.

- **Snapshots** go under `tests/snapshots/instructions/`:

    - `claude-block.md` and `codex-block.md` hold the rendered block bodies, that
      is, each artifact's `content`.
    - `concise.md` holds the rendered file.

    Write them from the rendered output once, then verify each against the live
    sources: `codex-block.md` equals `cat rules.md; echo; cat style.md`, and
    `concise.md` equals the live file (`cmp`). Record the `cmp` results in
    `## Result`.

## Tests first

`tests/test_instructions.py`. It uses a `home` fixture as in
`tests/test_adapters.py` (`HOME` and `RNF_HOME` under `tmp_path`, no
monkeypatching of `adapters`), and that file's `machine(home)` helper, copied,
to build the target and sources. `ASSETS_DIR` is
`Path(rn_forge.agentkit.__file__).parent / "assets" / "instructions"`, and
`SNAP` is `Path(__file__).parent / "snapshots" / "instructions"`. Get each
rendered artifact by path from
`adapters.render(target, [Agent.CLAUDE, Agent.CODEX], sources)`.

1. `test_s2_1_1_rules_once_style_only_for_codex`: let `rules` and `style` be the
   asset texts.
    - In the Claude block content, `rules` appears exactly once
      (`str.count == 1`) and `"# Output Style: Concise"` does not appear.
    - In the Codex block content, `rules` appears once and `style` appears once.
    - In `concise.md`, `style` appears once.
1. `test_s2_1_1_rendered_outputs_match_snapshots`: the Claude block content,
   Codex block content and `concise.md` content equal
   `(SNAP / name).read_text()` for each snapshot. The Codex content also
   equals `rules + "\n" + style`.
1. `test_s2_1_1_block_lands_after_an_existing_body`: write
   `<home>/.claude/CLAUDE.md` as `"# Mine\n\nKeep me.\n"`, then
   `run(app, ["apply"]) == ExitCode.OK`. The file starts with
   `"# Mine\n\nKeep me.\n\n<!-- BEGIN rn-forge agentkit -->\n"`, and
   `ManagedBlock.remove` of its text gives back `"# Mine\n\nKeep me.\n"`.
1. `test_s2_1_1_absent_file_holds_only_the_block`: after `apply`,
   `<home>/.codex/AGENTS.md` reads exactly
   `"<!-- BEGIN rn-forge agentkit -->\n" + rules + "\n" + style + "<!-- END rn-forge agentkit -->\n"`.
   Commons re-terminates the body, so read `ManagedBlock._block_text` and
   `render` in commons `fs/blocks.py` and assert the exact bytes they produce.
1. `test_s2_1_1_block_edit_is_drift_body_edit_is_not`: `apply`, then:
    - Insert `"# Mine\n\n"` before the block in `<home>/.claude/CLAUDE.md`.
      `apply` exits 0.
    - Then change a line inside the block, for example replace `Bias to action`
      with `Bias`. `apply` exits 1, and the captured output names
      `.claude/CLAUDE.md` and `drift`.
