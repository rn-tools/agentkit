# S2.2.2 — CLAUDE.md seed

Brief for [S2.2.2](../F2.2-repository-block.md#s222-claudemd-seed), at `7d916f8`
plus S2.2.1.

## Goal

At repo scope, `apply` seeds `<repo>/CLAUDE.md` as `@AGENTS.md` when it is
absent, and never reads or rewrites it after that. This follows ADR-0002:
`AGENTS.md` is canonical, and the repo's `CLAUDE.md` gets no agentkit block.

## Settled

- **Where:** `src/rn_forge/agentkit/repository.py`, added by S2.2.1. At repo
  scope, `render` always returns
  `Artifact("CLAUDE.md", ArtifactKind.SEEDED, "@AGENTS.md\n")`, whatever the
  `[repo]` keys or `--agent` are. It comes after the `AGENTS.md` block when
  that block is present. Name the content `CLAUDE_SEED = "@AGENTS.md\n"`.
- **Commons does the rest.**
    - A seeded artifact plans `create` when the path is absent and `skip` when it
      exists, without reading it (`classify`, commons
      `generation/plan.py:66-67`).
    - It is recorded as a seeded state entry with no `content_hash`
      (`Artifact.to_entry`, `generation/artifacts.py:138`).
    - On `remove`, its entry is `forget`, and the file stays.
    - Write no code for any of this.

## Current behaviour

- After S2.2.1, `repository.render` returns only the optional `AGENTS.md` block.
  Repo-scope `apply` never writes `CLAUDE.md`.
- `tests/test_claude_seed.py` fails on its first assertion: `CLAUDE.md` does not
  exist after `apply`.

## Tests first

`tests/test_claude_seed.py`, with the same `home` and `repo` fixtures as
`tests/test_repo_block.py`, copied. The repo has no `CLAUDE.md` unless a test
writes one. Use
`REPO_APPLY = ["apply", "--scope", "repo", "--repo", str(repo)]`.

1. `test_s2_2_2_absent_claude_md_is_seeded`: `apply`, then
   `(repo / "CLAUDE.md").read_bytes() == b"@AGENTS.md\n"`. The entry is
   `StateStore(repo / ".rn-forge/agentkit/state.json", entry_type=StateEntry).load()["CLAUDE.md"]`.
   Its `kind` is `ArtifactKind.SEEDED` and its `content_hash` is `None`.
1. `test_s2_2_2_present_claude_md_is_never_read_or_rewritten`: write `CLAUDE.md`
   as the bytes `b"\xff\xfe not utf-8\n"`. Any attempt to read it as text
   would raise. Run `apply` twice. Both runs exit 0, and the bytes are
   unchanged after each. The second run is `--json apply`, and it reports
   `CLAUDE.md` as `skip`.
1. `test_s2_2_2_seed_survives_a_hand_edit`: `apply`, rewrite `CLAUDE.md` as
   `"@AGENTS.md\n\n## Claude-only\n"`, then `apply` again. It exits 0, with no
   drift, and the edited text stays.
1. `test_s2_2_2_remove_keeps_claude_md`: `apply`, then
   `remove --scope repo --repo <repo>`. It exits 0, `CLAUDE.md` still reads
   `@AGENTS.md\n`, and the state holds no `CLAUDE.md` entry.
