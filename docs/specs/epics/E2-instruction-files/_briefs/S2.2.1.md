# S2.2.1 — AGENTS.md block from the repo overlay

Brief for
[S2.2.1](../F2.2-repository-block.md#s221-agentsmd-block-from-the-repo-overlay),
at `7d916f8`.

## Goal

At repo scope, `apply` writes agentkit's fenced block into `<repo>/AGENTS.md`.
The block is rendered from the `[repo]` overlay table. With no `[repo]` keys
set, there is no block. This adds `rn_forge.agentkit.repository`, the home of
the repository-scope artifacts, which S2.2.2 and S2.2.3 extend.

## Settled

- **A module of its own, outside the adapter seam.** Repository artifacts belong
  to the scope, not to an agent. They render at repo scope whatever `--agent`
  says, and never at machine scope. They live in
  `src/rn_forge/agentkit/repository.py`, not in `adapters`, which S1.4.1
  rebuilds in parallel.

- **Wiring:** in `operations.build_plan` (`operations.py:37`), the line
  `artifacts = adapters.render(target, agents, sources)` becomes
  `artifacts = [*adapters.render(target, agents, sources), *repository.render(target, sources)]`.
  That is the only edit to `operations.py`.

- **`repository.render(target: Target, sources: MergeResult) -> list[Artifact]`**:

    - It returns `[]` unless `target.scope is Scope.REPO`.
    - Otherwise it reads `table = sources.config.get("repo", {})`, validates it,
      and returns
      `[Artifact("AGENTS.md", ArtifactKind.BLOCK, body, AGENTS_BLOCK)]` when
      `body` is non-empty, else `[]`.
    - `AGENTS_BLOCK = ManagedBlock("rn-forge agentkit", comment="<!--")`. Its
      markers are `<!-- BEGIN rn-forge agentkit -->` and
      `<!-- END rn-forge agentkit -->`, matching F2.1's machine blocks.

- **Validation** raises `SourceError` (from `rn_forge.agentkit.sources`) when:

    - a `[repo]` key is not one of `worktree_root`, `shared_checkout` or
      `story_workflow`. Message:
      `"[repo] {key!r}: unknown key; expected one of worktree_root, shared_checkout, story_workflow"`.
    - `worktree_root` or `story_workflow` is not a `str`, or `shared_checkout` is
      not a `bool` (`type(value) is bool`). Message:
      `"[repo] {key!r}: expected {type name}, got {value!r}"`.

    Raise each with `SourceError(<format>, <args>)`, as `sources.py:69` does. The
    CLI maps it to exit 1, with the message on stderr.

- **`agents_block(table: Mapping[str, Any], repo_name: str) -> str`** builds the
  block body. It renders these lines, in this order, each only when its
  condition holds:

    1. `worktree_root` is a non-empty string:
       `` - Worktrees: create each one under `<value>`. `` Every `{repo}` in the
       value is replaced with `repo_name`, using `str.replace`, not
       `str.format`.
    1. `shared_checkout` is `True`:
       `` - Shared checkout: commit by explicit path, never `git add -A`, and re-check HEAD before committing. ``
    1. `story_workflow` is a non-empty string: `- Story workflow: <value>`. The
       value has its whitespace collapsed (`" ".join(value.split())`), so that a
       multi-line TOML string stays one bullet.

    With no lines, it returns `""`. Otherwise it returns
    `"## Agent workflow\n\n" + "\n".join(lines) + "\n"`. `render` passes
    `target.root.name` as `repo_name`.

- **Placement and removal are commons'.**

    - An absent block is appended after the file's text, separated by one blank
      line (`ManagedBlock.render`, commons `fs/blocks.py:183`).
    - A stale entry whose block is clean plans `remove`. `ManagedBlock.remove`
      drops the block and that one blank line (`fs/blocks.py:217`), so render
      and then remove leaves the file byte-identical.
    - Nothing here re-implements either.

- **Precedence** is the existing merge: packaged defaults set no `[repo]` table.
  The user overlay's `[repo]` applies to every repository, and the repo
  overlay `<repo>/.rn-forge/agentkit/config.toml` wins.

## Current behaviour

- `src/rn_forge/agentkit/operations.py:37`: artifacts come from
  `adapters.render` only. `adapters.render` returns `[]`
  (`adapters.py:13-17`). Repo-scope `apply` writes nothing but the state file.
- `src/rn_forge/agentkit/sources.py:18`: `TABLES` already includes `"repo"`, so
  `load_overlay` accepts a `[repo]` table, and `load_sources` merges it at
  repo scope only (`sources.py:86`).
- `tests/test_repo_block.py` fails at collection with `ModuleNotFoundError`
  (`rn_forge.agentkit.repository`).

## Tests first

`tests/test_repo_block.py`. Fixtures:

- `home`: as in `tests/test_apply.py` (`HOME` and `RNF_HOME` under `tmp_path`),
  without the `adapters.render` monkeypatch.

- `repo`: `tmp_path / "myrepo"`, initialised with
  `subprocess.run(["git", "init", "-q", str(repo)], check=True)`, as in
  `tests/test_remove.py:96-98`. It holds `AGENTS.md` written as `KILN_AGENTS`:

    ```python
    KILN_AGENTS = (
        "# AGENTS.md\n\nBody text.\n\n"
        "<!-- BEGIN rn-forge kiln -->\n## Repository standard (kiln)\n\n"
        "kiln text.\n<!-- END rn-forge kiln -->\n"
    )
    ```

- A helper `overlay(repo, text)` writes `<repo>/.rn-forge/agentkit/config.toml`.

- Run commands with
  `run(app, ["apply", "--scope", "repo", "--repo", str(repo)])`.

The full block for all three keys, with `worktree_root = "../{repo}-wt/"`,
`shared_checkout = true` and `story_workflow = "Pick a story;\n  build it."` (a
TOML multi-line basic string), is:

```python
BLOCK = (
    "<!-- BEGIN rn-forge agentkit -->\n"
    "## Agent workflow\n\n"
    "- Worktrees: create each one under `../myrepo-wt/`.\n"
    "- Shared checkout: commit by explicit path, never `git add -A`, "
    "and re-check HEAD before committing.\n"
    "- Story workflow: Pick a story; build it.\n"
    "<!-- END rn-forge agentkit -->\n"
)
```

1. `test_s2_2_1_no_keys_no_block`: no overlay.
   `--json plan --scope repo --repo <repo>` lists no change whose `path` is
   `AGENTS.md`. After `apply`, `AGENTS.md == KILN_AGENTS`.
1. `test_s2_2_1_block_lands_after_kiln_block`: overlay all three keys, then
   `apply`. `AGENTS.md` reads exactly `KILN_AGENTS + "\n" + BLOCK`, and
   `ManagedBlock("rn-forge kiln", comment="<!--").extract(...)` is the same
   before and after.
1. `test_s2_2_1_unsetting_keys_removes_block`: overlay all three keys and
   `apply`. Then overlay `""` and `apply` again. `AGENTS.md == KILN_AGENTS`
   exactly.
1. `test_s2_2_1_repo_placeholder_is_the_directory_name`:
   `agents_block({"worktree_root": "../{repo}-wt/"}, "myrepo")` is exactly
   `` "## Agent workflow\n\n- Worktrees: create each one under `../myrepo-wt/`.\n" ``.
1. `test_s2_2_1_only_set_keys_render`:
   `agents_block({"shared_checkout": False, "story_workflow": ""}, "r") == ""`.
   `agents_block({"shared_checkout": True}, "r")` holds only the
   shared-checkout bullet.
1. `test_s2_2_1_bad_repo_key_fails`: overlay `[repo]\nworktree-root = "x"\n`.
   `apply` returns 1, and the captured output names `'worktree-root'`. Overlay
   `[repo]\nshared_checkout = "yes"\n`: `apply` returns 1, and the output
   names `'shared_checkout'`.
1. `test_s2_2_1_machine_scope_renders_nothing`: write the user overlay
   `<home>/.rn-forge/share/agentkit/config.toml` as
   `[repo]\nshared_checkout = true\n`. For a machine target and its sources,
   built as in `tests/test_sources.py`,
   `repository.render(target, sources) == []`.
