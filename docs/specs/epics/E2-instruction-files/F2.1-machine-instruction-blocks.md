One packaged instruction source rendered to the agentkit block in
`~/.claude/CLAUDE.md` and `~/.codex/AGENTS.md`, plus the managed
`~/.claude/output-styles/concise.md`.

## Design

Sources live under `src/rn_forge/agentkit/instructions/`: `rules.md` (shared
working rules) and `style.md` (the concise output style, including the
clarifications bullets). The text is ported from
`rn_backup/agentkit/src/rn_forge/agentkit/assets/instructions/{behavior,style,clarifications}.md`,
updated to the live 2026-11-14 text of `~/.claude/CLAUDE.md` minus body-only
lines. The "Model routing and token economy" section of the live
`~/.codex/AGENTS.md` and the `dev-team-orchestration` bullet of the live
`~/.claude/CLAUDE.md` both go into `rules.md` (owner, 2026-11-19), and leave
those files' bodies at cutover.

- **Claude block:** rules.
- **Codex block:** rules plus style.
- **`concise.md`:** output-style front matter plus style.
- **Block markers:** `<!-- BEGIN rn-forge agentkit -->` and
  `<!-- END rn-forge agentkit -->` (commons `ManagedBlock`, HTML-comment
  style).

## S2.1.1 — Render the shared source to both blocks and the output style

**State:** Closed (2026-11-20)

**Acceptance:**

- Contract: `assets/instructions/rules.md` is the live `~/.claude/CLAUDE.md`
  with the live Codex "Model routing and token economy" section after "Bias to
  action"; `style.md` is the live concise style. The Codex block is rules, a
  blank line, then style; `concise.md` byte-matches the live file.

- The rules text appears exactly once in each rendered block; the style text
  appears in the Codex block and in `concise.md` and not in the Claude block.

- Snapshot tests: each rendered block and `concise.md` byte-match committed
  snapshots under `tests/snapshots/`.

- Applying into a file with an existing body inserts the block after the body
  and leaves the body byte-identical.

- A file that does not exist is created containing only the block.

- Editing text inside the block on disk is drift; editing the body is not.

## Considered and rejected

- **Model routing in the Codex body only.** Rejected (owner, 2026-11-19): it
  governs delegation for both agents, so it is shared rules.
- **`dev-team-orchestration` bullet in the Claude body only.** Rejected (owner,
  2026-11-19): the skill ships for both agents
  ([F3.2](../E3-asset-pack/F3.2-skills.md)), so the bullet is shared rules.
