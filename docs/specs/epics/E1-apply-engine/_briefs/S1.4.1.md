# S1.4.1 — Adapter seam with file and block artifacts

Brief for
[S1.4.1](../F1.4-agent-adapters.md#s141-adapter-seam-with-file-and-block-artifacts),
at `7d916f8`.

## Goal

Turn `rn_forge.agentkit.adapters` from a stub into the seam F2.1, F3.1 and F3.2
fill in: a Claude and a Codex adapter as plain data, each listing artifact specs
per scope, rendered into commons `Artifact`s. Executable specs end up mode 0755
after `apply`. `--agent` stops touching the files of agents it did not select.
No content is packaged yet: both real adapters have empty spec lists, and the
tests use fixture adapters.

## Settled

- **Package layout** (F1.4 Design: "each adapter is a module of plain data"):

    - `src/rn_forge/agentkit/adapters.py` becomes the package
      `src/rn_forge/agentkit/adapters/`.
    - `adapters/spec.py` holds the two types, `ArtifactSpec` and `Adapter`.
    - `adapters/claude.py` and `adapters/codex.py` each define one constant,
      `ADAPTER`, and import only from `spec.py`, `sources` and `targets`. The
      split exists to avoid a circular import.
    - `adapters/__init__.py` holds `ASSETS`, `ADAPTERS`, `render`, `owned_paths`
      and `executable_paths`, and re-exports `ArtifactSpec` and `Adapter`.

- **`ArtifactSpec`** is a `@dataclass(frozen=True, slots=True)` with these
  fields, in order:

    - `path: str`: POSIX path relative to the scope root (`$HOME` at machine
      scope, the repository at repo scope).
    - `kind: ArtifactKind`
    - `source: str`: path of the packaged asset, relative to `ASSETS`.
    - `template: bool = False`: `True` renders `source` through the commons
      template engine. `False` copies it verbatim. Hook scripts contain `{#` and
      `${...}`, which Jinja would misread, so verbatim is the default.
    - `block: ManagedBlock | None = None`
    - `executable: bool = False`

    `__post_init__` raises `ValueError` ("rejected at load") when:

    - `path` is empty or absolute (`PurePosixPath(path).is_absolute()`), or any of
      its parts is `..`. The message names the path and says it must stay inside
      the scope root.
    - `(kind is ArtifactKind.BLOCK) != (block is not None)`, the same rule as
      commons `Artifact`, checked here so that a bad spec fails at import.
    - `executable` is true and `kind` is not `ArtifactKind.MANAGED`.

- **`Adapter`** is a `@dataclass(frozen=True, slots=True)` with `agent: Agent`
  and `specs: Mapping[Scope, tuple[ArtifactSpec, ...]]`. A scope that is not
  in `specs` has no artifacts. The real `claude.ADAPTER` and `codex.ADAPTER`
  are `Adapter(Agent.CLAUDE, {})` and `Adapter(Agent.CODEX, {})` in this
  story. F2.1, F3.1 and F3.2 add the specs.

- **`ASSETS`** is `Path(str(files("rn_forge.agentkit").joinpath("assets")))`.
  The directory need not exist yet. `uv_build` packages the non-Python files
  under the module, as it already does for `defaults/*.toml`. Tests
  monkeypatch `adapters.ASSETS`.

- **`ADAPTERS`** is `dict[Agent, Adapter]`:
  `{Agent.CLAUDE: claude.ADAPTER, Agent.CODEX: codex.ADAPTER}`. Tests
  monkeypatch it.

- **`render(target, agents, sources) -> list[Artifact]`** keeps its signature,
  because the existing tests monkeypatch it.

    - For each agent in `agents`, in order, and for each spec in
      `ADAPTERS[agent].specs.get(target.scope, ())`, in order, it builds
      `Artifact(spec.path, spec.kind, content, block=spec.block)`.
    - Verbatim content is `(ASSETS / spec.source).read_text(encoding="utf-8")`.
    - Template content is
      `TemplateEngine.cached(directory=str(ASSETS)).render(spec.source, context)`,
      with `TemplateEngine` from `rn_forge.commons.text.templates`. The engine
      keeps trailing newlines and uses strict undefined. Never import `jinja2`:
      `.importlinter` forbids it.
    - `context` is
      `{"agent": agent.value, "scope": target.scope.value, "config": sources.config.get(agent.value, {})}`.

- **`owned_paths(scope, agents) -> frozenset[str]`** and
  **`executable_paths(scope, agents) -> frozenset[str]`** are the union of the
  spec paths, or of the executable spec paths, that `ADAPTERS[a]` declares for
  `scope`, over each `a` in `agents`. They are static: no rendering, no assets
  read.

- **`--agent` keeps other agents' state.** `plan` treats every state entry that
  is not rendered as stale and deletes it (commons `plan.py:150`). Commons
  `apply` then rewrites state from the plan alone (`_next_entries`). So today
  `apply --agent claude` would delete codex's files. The fix is in
  `operations.py`:

    - `build_plan` computes
      `others = adapters.owned_paths(target.scope, [a for a in Agent if a not in agents])`.
    - It splits the loaded entries into `kept` (entry path in `others`) and the
      rest.
    - It plans with the rest only, and returns `(plan, rest, kept)`.
    - Entries at paths no adapter declares, such as F2.2's repository artifacts,
      or a spec a later version drops, are always planned.

- **Kept entries survive the state write.** Add `_KeepingStore`, a private
  subclass of `StateStore[StateEntry]` in `operations.py`:

    - `__init__(self, path: Path, keep: Mapping[str, StateEntry])` calls
      `super().__init__(path, entry_type=StateEntry)` and stores `dict(keep)`.
    - `replace_all(self, entries)` calls
      `super().replace_all({**self._keep, **entries})`.

    `run_apply` passes `_KeepingStore(target.state_path, kept)` as commons
    `apply`'s `store`. That keeps a single atomic state write.

- **Mode 0755 through `verify`.** `run_apply` passes commons `apply` a `verify`
  callback.

    - The callback calls `make_executable(target.root / path)` for each path,
      sorted, in
      `adapters.executable_paths(target.scope, agents) & {c.path for c in planned.changes if c.artifact is not None}`.
    - `make_executable(path: Path) -> None` is a public function in
      `operations.py` that runs `path.chmod(0o755)`. It is public so the
      rollback test can monkeypatch it. Patching `os.chmod` would also break
      commons' rollback copies.
    - Commons calls `verify` after every write and before the state write. A raise
      rolls the whole apply back and surfaces as `AppException` ("Apply failed
      and was rolled back: …"), so the CLI exits 1. A dry run returns before
      `verify`.

- **Callers of `build_plan`:** `run_apply` uses all three values. `run_diff`
  unpacks `planned, _, _`. `commands.plan` keeps `build_plan(...)[0]` and does
  not change. `run_remove` does not call `build_plan` and does not change.
  `remove` has no `--agent` and takes back the whole scope (F1.3).

- **Leave the artifact line alone.** In `build_plan`, keep the line
  `artifacts = adapters.render(target, agents, sources)` byte-identical.
  S2.2.1 edits that line in parallel. Add the entry split after the
  `entries = …` line.

## Current behaviour

- `src/rn_forge/agentkit/adapters.py:13-17`: `render` returns `[]`. There is no
  package, no spec type and no registry.
- `src/rn_forge/agentkit/operations.py:28-39`: `build_plan` returns
  `(plan, entries)` and plans every entry.
- `operations.py:42-59`: `run_apply` passes `_store(target)` and no `verify`.
- `src/rn_forge/agentkit/defaults/{claude,codex}.toml` hold only a comment, so
  `sources.config` is `{}` unless an overlay sets keys.
- The new test module fails at collection with `ModuleNotFoundError`
  (`rn_forge.agentkit.adapters` is not a package), or with `ImportError`
  (`ArtifactSpec`) once it is.

## Tests first

Write `tests/test_adapters.py` before the change. Use the `home` fixture shape
of `tests/test_apply.py` (`HOME` and `RNF_HOME` set under `tmp_path`), without
its `adapters.render` monkeypatch. Add a `fake` fixture that:

- Writes these assets into `tmp_path / "assets"`, then monkeypatches
  `adapters.ASSETS` to that directory:
    - `one.md`: `"one {# kept #}\n"`
    - `seed.md`: `"seed\n"`
    - `rules.md.j2`: `"agent={{ agent }} effort={{ config.effort }}\n"`
    - `hook.sh`: `"#!/bin/sh\necho ${#}\n"`
    - `codex.md`: `"codex\n"`
- Monkeypatches `adapters.ADAPTERS` to
  `{Agent.CLAUDE: Adapter(Agent.CLAUDE, {Scope.MACHINE: CLAUDE_SPECS}), Agent.CODEX: Adapter(Agent.CODEX, {Scope.MACHINE: (ArtifactSpec(".fake-codex/one.md", ArtifactKind.MANAGED, "codex.md"),)})}`.
  `CLAUDE_SPECS` are, in order:
    - `ArtifactSpec(".fake-claude/one.md", MANAGED, "one.md")`
    - `ArtifactSpec(".fake-claude/seed.md", SEEDED, "seed.md")`
    - `ArtifactSpec(".fake-claude/rules.md", BLOCK, "rules.md.j2", template=True, block=ManagedBlock("rn-forge agentkit", comment="<!--"))`
    - `ArtifactSpec(".fake-claude/hook.sh", MANAGED, "hook.sh", executable=True)`
- Writes the user overlay `<home>/.rn-forge/share/agentkit/config.toml` as
  `[claude]\neffort = "high"\n`.

Build a target with
`resolve_target(Scope.MACHINE, repo=None, cwd=home, home=home, rnf_home=home / ".rn-forge")`,
and sources with
`load_sources(Scope.MACHINE, user_overlay=target.user_overlay, repo_overlay=target.repo_overlay)`.

1. `test_s1_4_1_no_two_artifacts_share_a_destination`: over the real
   `adapters.ADAPTERS`, without the `fake` fixture, and for each `Scope`, the
   spec paths across all adapters have no duplicates. It passes vacuously
   today and guards F2.1, F3.1 and F3.2.
1. `test_s1_4_1_render_returns_only_selected_agents`: with `fake`,
   `render(target, [Agent.CLAUDE], sources)` returns the four `.fake-claude/`
   paths in spec order and no `.fake-codex/` path.
   `render(target, [Agent.CODEX], sources)` returns only `.fake-codex/one.md`.
   A repo-scope target, built with
   `resolve_target(Scope.REPO, repo=<tmp dir>, …)`, renders `[]`.
1. `test_s1_4_1_specs_render_to_commons_artifacts`: with `fake`, the claude
   artifacts are commons `Artifact`s with these kinds and contents:
    - `MANAGED`, content `"one {# kept #}\n"`: copied verbatim, not templated.
    - `SEEDED`, content `"seed\n"`.
    - `BLOCK`, with `block == ManagedBlock("rn-forge agentkit", comment="<!--")`
      and content `"agent=claude effort=high\n"`.
    - `MANAGED`, content `"#!/bin/sh\necho ${#}\n"`.
1. `test_s1_4_1_executable_is_0755_after_apply`: with `fake`,
   `run(app, ["apply"]) == ExitCode.OK`, and
   `stat.S_IMODE((home / ".fake-claude/hook.sh").stat().st_mode) == 0o755`.
1. `test_s1_4_1_failing_chmod_rolls_back`: with `fake`, monkeypatch
   `operations.make_executable` to raise `OSError("boom")`. Then
   `run(app, ["apply"]) == 1`, none of the five `.fake-*` files exists, and
   `<home>/.rn-forge/share/agentkit/state.json` does not exist.
1. `test_s1_4_1_escaping_path_is_rejected_at_load`: each of `"../outside.md"`,
   `"a/../../b"`, `"/etc/passwd"` and `""` raises `ValueError` from
   `ArtifactSpec(<path>, ArtifactKind.MANAGED, "x")`. Also raising
   `ValueError`:
    - `ArtifactSpec("a.sh", ArtifactKind.SEEDED, "x", executable=True)`
    - `ArtifactSpec("a.md", ArtifactKind.BLOCK, "x")`, which has no block.
1. `test_s1_4_1_agent_filter_keeps_other_agents_files`: with `fake`:
    - `run(app, ["apply"]) == ExitCode.OK`.
    - Then `run(app, ["apply", "--agent", "claude"]) == ExitCode.OK`.
      `.fake-codex/one.md` still exists, and the state file still has an entry
      whose path is `.fake-codex/one.md`. Load it with
      `StateStore(<state>, entry_type=StateEntry).load()`.
    - Then `--json apply` reports every change `unchanged` or `skip`.
