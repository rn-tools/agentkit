# S1.3.3 — remove

Brief for [S1.3.3](../F1.3-commands.md#s133-remove), at `2c24025`.

## Goal

Add `agentkit remove`. It takes back everything agentkit recorded in a scope:
managed files deleted, blocks removed, bodies left alone. A file edited by hand
since agentkit wrote it is left in place and reported. At machine scope,
`remove` may then delete the share dir, after a confirmation.

## Settled

- **Remove is a plan with no artifacts:** `plan(target.root, [], entries)`. For
  each stale entry, commons then plans:
    - a clean managed file: `delete`;
    - a clean block: `remove`, with the file body untouched;
    - a seeded file, or a file already gone: `forget`;
    - a hand-edited file or block: `drift`. Key-path entries join through the same
      route once S1.2.2 lands, with no change here.
- **Drift is left in place:** the plan passed to commons `apply` keeps only the
  changes that are not `is_blocking`. Each blocking change is reported, and
  its file is not touched. Commons `apply` rewrites state from the remaining
  plan (`store.replace_all(_next_entries(planned))`, `apply.py:158`), so after
  `remove` the state holds no entries, the drifted one included. `remove`
  exits 0 when drift is left in place: it is reported, not an error.
- **Backups:** commons `apply` backs up every deleted or rewritten file under
  `<work dir>/backups/<UTC stamp>/` first. Nothing extra is needed.
- **Share dir prompt, machine scope only:**
    - After the apply, `remove` asks
      `console.confirm("Delete <work dir>, including its backups and your overlay?", default=False)`.
    - `--yes` (`rn_forge.cli.YesOption`) skips the prompt and deletes.
    - A no answer leaves the share dir in place.
    - Deleting is `shutil.rmtree(target.work_dir)`.
    - At repository scope there is no prompt: `.rn-forge/agentkit/` stays, with
      its state emptied.
- **Options:** `--scope`, `--repo` and `--yes`. There is **no `--agent`**: state
  entries carry no agent until F1.4's adapters, so `remove` always removes the
  whole scope. Record this on the story when it closes.
- **Output:**
    - Text: one line `<action> <path>` per applied change, then
      `left in place (drift): <path>` per drifted path.
    - JSON: `{"changes": [{"path","kind","action"}, ...], "left": [<path>, ...]}`.
- **README:** a new `## Uninstall` section after `## Working here`. It says to
  run `agentkit remove --scope machine`, and `agentkit remove --scope repo` in
  each repository that used agentkit, before the lifecycle
  `agentkit uninstall`. It also says that `uninstall` alone leaves the
  configuration agentkit wrote. `README.md` is repo-owned, not kiln-generated,
  so edit it directly.
- **Wiring:** add `[[cli.commands]] name = "remove"`,
  `target = "rn_forge.agentkit.commands:remove"` after `plan` in
  `.rn-forge/kiln/config.toml`, then run `task kiln:apply`.

## Current behaviour

- `src/rn_forge/agentkit/operations.py` has `build_plan`, `run_apply` and
  `run_diff`. `commands.py` has `apply`, `diff` and `plan`. There is no
  `remove`.
- `README.md` has `## Working here` and `## Conventions`, and no uninstall
  section.
- The new tests fail with `ImportError` (`run_remove`), or with exit 2
  (`No such command 'remove'`) for CLI tests. The README test fails on the
  missing text.

## Change

- **Change:**
    - `src/rn_forge/agentkit/operations.py`: add
      `run_remove(target: Target) -> tuple[ApplyResult, list[Change]]`. It loads
      entries, plans with no artifacts, splits the changes into blocking and
      non-blocking, applies a `Plan` of the non-blocking ones (passing
      `entries`), and returns the result with the blocking changes.
    - `src/rn_forge/agentkit/commands.py`: add `remove(scope, repo, yes)`, thin
      over `run_remove`, with the prompt and `rmtree` as settled.
    - `.rn-forge/kiln/config.toml` plus `task kiln:apply`.
    - `README.md`: the `## Uninstall` section.
    - New `tests/test_remove.py` (below).
- **Leave alone:** `sources.py`, `targets.py`, `adapters.py`, `findings.py`,
  `product.py`, the existing tests, `pyproject.toml`, `uv.lock`, generated
  files except through `task kiln:apply`, and every doc page except this
  brief's `## Result`.
