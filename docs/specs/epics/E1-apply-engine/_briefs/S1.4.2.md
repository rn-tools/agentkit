# S1.4.2 — The two settings artifacts

Brief for [S1.4.2](../F1.4-agent-adapters.md#s142-the-two-settings-artifacts),
at the commit that adds this brief (parent `01f3fe8`).

## Goal

At machine scope, own the F1.4 key paths in `~/.claude/settings.json` and
`~/.codex/config.toml` as `keys` artifacts (S1.2.2), with values from new
packaged defaults ported from the old agentkit. Every other key in those files
is left alone. The Claude `hooks` key is S3.1.2's, not this story's.

## Settled

- **New spec module** `src/rn_forge/agentkit/adapters/settings.py`, in the style
  of `adapters/instructions.py`:

    ```python
    CLAUDE: tuple[ArtifactSpec, ...] = (
        ArtifactSpec(
            ".claude/settings.json",
            ArtifactKind.KEYS,
            "",
            keys=("effortLevel", "extraKnownMarketplaces", "outputStyle", "permissions.deny"),
        ),
    )
    CODEX: tuple[ArtifactSpec, ...] = (
        ArtifactSpec(
            ".codex/config.toml",
            ArtifactKind.KEYS,
            "",
            keys=(
                "approval_policy",
                "features.hooks",
                "model_reasoning_effort",
                "model_reasoning_summary",

                "profiles.trusted",

                "sandbox_workspace_write.network_access",
    ```

    `hooks` is deliberately absent from the Claude list. S3.1.2 adds it with
    values rendered from `RNF_HOME`.

- **Splice** them in `adapters/claude.py` and `adapters/codex.py`, after the
  existing three:
  `(*instructions.CLAUDE, *hooks.CLAUDE, *skills.CLAUDE, *settings.CLAUDE)`,
  and the same for Codex.

- **Packaged defaults.** Replace the one comment line in each of
  `src/rn_forge/agentkit/defaults/claude.toml` and `codex.toml` with the
  values ported from
  `/Users/rohitnarayanan/Devel/workspaces/rn_backup/agentkit/src/rn_forge/agentkit/agents/{claude,codex}/defaults/global.{json,toml}`
  (read-only):

    - `claude.toml`: `effortLevel = "medium"`, `outputStyle = "concise"`, a
      `[permissions]` table with `deny` holding the 21 `Read(...)` globs in the
      old order, and an
      `[extraKnownMarketplaces.claude-plugins-official.source]` table with
      `source = "github"` and `repo = "anthropics/claude-plugins-official"`. Do
      not port the old `hooks` value.
    - `codex.toml`: the old `global.toml` as it stands, with its comments and
      every key: `personality`, `model_reasoning_effort`,
      `model_reasoning_summary`, `approval_policy`, `sandbox_mode`,
      `[sandbox_workspace_write]`, `[features]`, `[profiles.trusted]` and
      `[profiles.deep]`.
    - Start each file with one comment line saying it is agentkit's packaged
      defaults for that agent, ported from v0.

    These tables are also the agents' template `config`. No current template reads
    any of these keys, so the existing renders do not change.

## Current behaviour

- `defaults/{claude,codex}.toml` hold one comment line each, so the merged
  config has no settings values.
- No spec names `.claude/settings.json` or `.codex/config.toml`. After `apply`
  in a temp `HOME`, a pre-written `settings.json` is byte-identical and no
  `config.toml` is created.
- So each new test fails on its first owned-value assertion: a `KeyError` on
  `effortLevel`, or `FileNotFoundError` for an absent file.

## Change

- **Change:** new `adapters/settings.py`; `adapters/claude.py` and
  `adapters/codex.py` (the splice); `defaults/claude.toml` and
  `defaults/codex.toml`; new `tests/test_settings.py` and its fixtures under
  `tests/fixtures/settings/`.
- **Existing tests:** if a test that runs the real adapters breaks only because
  apply now also writes these two files (for example an exact list of changed
  paths), update that assertion and record it in `## Result`. Change nothing
  else in it.
- **Leave alone:** every other module, `pyproject.toml`, `uv.lock`, every
  kiln-generated file, and every doc page except this brief's `## Result`.

## Tests first

`tests/test_settings.py`, with a temp `HOME` and `RNF_HOME = HOME/.rn-forge`
(the `isolated_env` shape in `tests/hooks/conftest.py`, or the `home` fixture of
`tests/test_keys.py`), running the real adapters.

Fixtures are **synthetic** files with the shape of the live 2026-11-14 files.
Use placeholder values, and no real paths, hosts, tokens or names.

- `tests/fixtures/settings/settings.json` holds every unowned Claude key:
  `model`, `availableModels` (list), `modelSettings` (object),
  `agentPushNotifEnabled`, `inputNeededNotifEnabled`, `remoteControlAtStartup`
  (booleans), `env` (object), `permissions.allow` and `permissions.ask`
  (lists). It also holds stale owned values that differ from the defaults:
  `effortLevel = "low"` and a two-item `permissions.deny`.
- `tests/fixtures/settings/config.toml` holds every unowned Codex key: `model`,
  `notify` (list), `[mcp_servers.example]`, `[plugins.example]`,
  `[marketplaces.example]`, `[projects."/placeholder/repo"]` with
  `trust_level`, `[desktop]`, and `[hooks.state]` with one placeholder entry.
  It has at least two comment lines, and stale owned values
  `model_reasoning_effort = "high"` and `personality = "friendly"`.

Copy each fixture into `HOME/.claude/` or `HOME/.codex/` before `apply`.

1. `test_s1_4_2_claude_owned_keys_only`: after `apply`, every unowned key equals
   the fixture's value (compare parsed values). `effortLevel == "medium"`,
   `outputStyle == "concise"`, `permissions.deny` is the 21-glob list,
   `extraKnownMarketplaces` equals the default, and there is no `hooks` key.
1. `test_s1_4_2_codex_owned_keys_only`: after `apply`, every unowned key and
   table equals the fixture's, both comment lines survive, and each of the
   nine owned paths equals the packaged default (for example
   `personality == "pragmatic"` and
   `profiles.trusted == {"approval_policy": "never"}`).
1. `test_s1_4_2_first_apply_inserts_without_force`: with both fixtures in place,
   `--json plan` rows for `.claude/settings.json` and `.codex/config.toml` are
   `insert`, and `apply` with no `--force` returns `ExitCode.OK`.
1. `test_s1_4_2_overlay_owned_key_is_applied`: a user overlay with
   `[claude]\neffortLevel = "high"\n` and
   `[codex.profiles.deep]\nmodel_reasoning_effort = "xhigh"\n`. After `apply`,
   `effortLevel == "high"` and
   `profiles.deep.model_reasoning_effort == "xhigh"`.
1. `test_s1_4_2_second_apply_is_unchanged`: `apply` twice; the second's `--json`
   rows for both files are `unchanged`.
1. `test_s1_4_2_agent_filter`: `apply --agent codex` with no files present
   creates `.codex/config.toml` and does not create `.claude/settings.json`.

Each fails before the change as **Current behaviour** says.
