# S1.2.2 — Key-path artifacts plan and apply

Brief for
[S1.2.2](../F1.2-owned-key-paths.md#s122-key-path-artifacts-plan-and-apply), at
the commit that adds this brief (parent `6e06bb5`).

## Goal

Let an adapter declare a `keys` artifact: named dotted key paths it owns inside
a JSON or TOML file another program also writes. The values come from the
agent's merged config. Classification, apply, rollback and removal are
rn-forge-commons 0.10.1's `ArtifactKind.KEYS`; agentkit only renders the
artifact and passes the previous state to `diff`. The real Claude and Codex
settings artifacts are S1.4.2, not this story.

## Settled

- **The commons floor is already moved.** `6e06bb5` pins
  `rn-forge-commons[templates]>=0.10.1,<0.11` and locks 0.10.1. Do not touch
  `pyproject.toml` or `uv.lock`.

- **`ArtifactSpec` gains `keys`** (`src/rn_forge/agentkit/adapters/spec.py`), as
  the last field: `keys: tuple[str, ...] = ()`. Document it in the class
  docstring's `Args:` as "Dotted key paths the artifact owns, for
  `ArtifactKind.KEYS` only; values come from the agent's merged config."
  `__post_init__` adds one rule, after the block rule:
  `if (self.kind is ArtifactKind.KEYS) != bool(self.keys): raise ValueError(f"artifact {self.path!r}: keys are required for, and only for, kind 'keys'")`.
  A keys spec's `source` is `""` and its `template` is `False`; nothing
  reads them.

- **Rendering** (`src/rn_forge/agentkit/adapters/__init__.py`):

    - `_emit` returns `Artifact | None`. For a `KEYS` spec it builds
      `values = {path: value for path in spec.keys if (value := DictUtils.get(config, path, default=_ABSENT)) is not _ABSENT}`,
      where `config` is `context["config"]` and `_ABSENT = object()` is a
      module constant. `DictUtils` is
      `rn_forge.commons.lang.collections.DictUtils`. It returns `None` when
      `values` is empty, else
      `Artifact(_destination(target, spec), ArtifactKind.KEYS, "", keys=values)`.
      Other kinds are unchanged.
    - `render` drops `None` results, in both the agent loop and the `COMMON` loop.
    - A path absent from the config is therefore not rendered. If it was applied
      before, commons plans its removal from the file.

- **`run_diff`** (`src/rn_forge/agentkit/operations.py`) passes the planned
  entries to commons `diff`: `diff(target.root, change, entries=entries)`,
  with `entries` the second value `build_plan` returns. Nothing else in
  `operations.py` changes.

- **`--force` names the file path** for a keys artifact (its state key is its
  path), as for a managed file.

## Current behaviour

- `ArtifactSpec` has no `keys` field: `ArtifactSpec(p, ArtifactKind.KEYS, "")`
  succeeds, and `ArtifactSpec(p, ArtifactKind.KEYS, "", keys=(...))` raises
  `TypeError: ... unexpected keyword argument 'keys'`.
- `_emit` builds `Artifact(path, KEYS, content)` with no `keys`, so a keys spec
  raises commons' `ValueError: ...: a keys artifact needs non-empty keys`.
- So every new test below fails at fixture set-up with that `TypeError`.

## Tests first

`tests/test_keys.py`. Copy the `home` fixture from `tests/test_adapters.py`, and
write a `fake` fixture in its style: monkeypatch `adapters.COMMON` to `{}` and
`adapters.ADAPTERS` to:

- Claude, machine scope:
  `ArtifactSpec(".fake-claude/settings.json", ArtifactKind.KEYS, "", keys=("effortLevel", "permissions.deny"))`
- Codex, machine scope:
  `ArtifactSpec(".fake-codex/config.toml", ArtifactKind.KEYS, "", keys=("approval_policy", "features.hooks"))`

and write the user overlay `<home>/.rn-forge/share/agentkit/config.toml`:

```toml
[claude]
effortLevel = "high"

[claude.permissions]
deny = ["Read(./.env)", "Read(./secrets/**)"]

[codex]
approval_policy = "never"

[codex.features]
hooks = true
```

`STATE = <home>/.rn-forge/share/agentkit/state.json`. Read JSON with
`json.loads`, TOML with `tomllib.loads`. Plan rows come from
`run(app, ["--json", "plan"])` and
`json.loads(capsys.readouterr().out)["changes"]`.

1. `test_s1_2_2_spec_requires_keys_for_kind_keys`:
   `ArtifactSpec("a.json", ArtifactKind.KEYS, "")` and
   `ArtifactSpec("a.md", ArtifactKind.MANAGED, "x", keys=("a",))` each raise
   `ValueError`.
1. `test_s1_2_2_insert_over_app_written_file`: write
   `.fake-claude/settings.json` as
   `{"model": "opus", "permissions": {"allow": ["Bash(ls)"]}, "env": {"B": "2", "A": "1"}}`.
   The plan row for it is `insert`. `apply` (no `--force`) returns
   `ExitCode.OK`, and the file's text equals
   `json.dumps(expected, indent=2, sort_keys=True)` plus a trailing newline if
   the writer adds one (compare after `.rstrip("\n")`). `expected` is the
   original document plus `effortLevel` and `permissions.deny`.
1. `test_s1_2_2_toml_comments_and_unowned_keys_survive`: write
   `.fake-codex/config.toml` with a top-of-file comment line, `model = "o3"`
   with a trailing comment, and a `[projects."/x"]` table with
   `trust_level = "trusted"` and a comment line above it. After `apply`, every
   comment line is still in the text, `model` and `projects` are unchanged,
   and `approval_policy == "never"` and `features.hooks is True`.
1. `test_s1_2_2_unowned_key_added_after_apply_is_unchanged`: after `apply`, add
   `"theme": "dark"` to the JSON file on disk. Both artifacts plan
   `unchanged`.
1. `test_s1_2_2_owned_value_changed_on_disk_is_drift`: after `apply`, set
   `effortLevel` to `"low"` on disk. The plan row is `drift`. `apply` returns
   1 and leaves the file as edited. `apply --force .fake-claude/settings.json`
   returns `ExitCode.OK`, `effortLevel` is `"high"` again, and at least one
   file exists under `<home>/.rn-forge/share/agentkit/backups/` (mirror
   `tests/test_apply.py`'s backup assertion).
1. `test_s1_2_2_list_is_compared_whole`: after `apply`, append `"Read(./x)"` to
   `permissions.deny` on disk. The plan row is `drift`.
1. `test_s1_2_2_dropped_path_is_removed`: write the JSON file with
   `{"permissions": {"allow": ["Bash(ls)"]}}`, `apply`, then monkeypatch the
   Claude spec to `keys=("effortLevel",)` and `apply` again. The file has
   `effortLevel`, has `permissions.allow`, and has no `permissions.deny`; the
   state entry's `key_paths == ("effortLevel",)`.
1. `test_s1_2_2_absent_config_path_is_not_rendered`: drop `[codex.features]`
   from the overlay. `adapters.render` for Codex returns one artifact whose
   `keys == {"approval_policy": "never"}`. Drop `[codex]` entirely and it
   returns no artifact.
1. `test_s1_2_2_absent_file_is_created_with_owned_keys_only`: with no files on
   disk, the plan rows are `create`; after `apply`, the JSON file is exactly
   `{"effortLevel": "high", "permissions": {"deny": [...]}}` and the TOML file
   holds only `approval_policy` and `features.hooks`.
1. `test_s1_2_2_remove_keeps_the_file`: write the JSON file with
   `{"model": "opus"}`, `apply`, then `remove --yes`. The file still exists
   and equals `{"model": "opus"}`.
1. `test_s1_2_2_diff_shows_owned_change`: after `apply`, change the overlay's
   `effortLevel` to `"medium"`. `diff` returns `ExitCode.OK` and its output
   contains a `-` line with `"high"` and a `+` line with `"medium"`.
