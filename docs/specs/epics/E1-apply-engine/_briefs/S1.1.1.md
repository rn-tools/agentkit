# S1.1.1 — Load and merge the three layers

Brief for
[S1.1.1](../F1.1-sources-and-layers.md#s111-load-and-merge-the-three-layers), at
`e17f25c`.

## Goal

Add `rn_forge.agentkit.sources`. It loads agentkit's three configuration layers
(packaged defaults, user overlay, repository overlay), deep-merges them in that
order of precedence, and records which layer won each key. Every later E1
feature reads its configuration through this module.

## Settled

- **Overlay shape** (F1.1 Design): an overlay file is TOML with one top-level
  table per name in `("claude", "codex", "repo")`. Any other top-level key,
  whether a table or a scalar, is an error naming that key and the file.
- **Merge** (F1.1 Design): tables merge recursively, and every other value,
  lists included, replaces. Use the existing commons `DictUtils.merge_layers`
  from `rn_forge.commons.lang.collections`. It already implements exactly
  this, with provenance. Pass named `(name, mapping)` layers and no
  `append_paths`. Do not write a merge of your own.
- **Layer names** (F1.1 Design): `packaged`, `user` and `repo`, in that
  precedence order (`repo` highest).
- **Provenance** is the `MergeResult.provenance` map from commons: a dotted key
  such as `claude.effortLevel` mapped to the layer name.
- **Packaged defaults** (F1.1 Design):
  `src/rn_forge/agentkit/defaults/claude.toml` and
  `src/rn_forge/agentkit/defaults/codex.toml`. Each file holds that agent's keys
  at top level, with no `[claude]` header. The loader wraps them as
  `{"claude": <claude.toml>, "codex": <codex.toml>}`. There is no packaged
  `repo` file (F2.2: packaged defaults set no `[repo]` keys). In this story
  both files hold only a one-line comment. Their real values are F1.4's job.
- **Overlay paths** (owner's lead, 2026-11-19):
    - User overlay: `<rnf_home>/share/agentkit/config.toml`. It lives in the share
      dir because lifecycle `uninstall` deletes `<rnf_home>/agentkit/`.
    - Repository overlay: `<repo root>/.rn-forge/agentkit/config.toml` (F4.3).
- **Missing overlay file:** an empty layer, read with
  `DocumentUtils.read(path, missing_ok=True)`. An overlay that fails to parse
  raises the commons `DocumentError` unchanged (its message already starts
  with the path).
- **Machine scope** ignores the repository overlay, even when one exists.

## Current behaviour

There is no `rn_forge.agentkit.sources` module and no `defaults/` directory.
`src/rn_forge/agentkit/` holds only the kiln stub (`commands.py` `hello`,
`main.py`, `product.py`). Every new test fails at collection with
`ModuleNotFoundError: No module named 'rn_forge.agentkit.sources'`.

## Change

- **Change:**
    - New `src/rn_forge/agentkit/sources.py`, containing exactly:
        - `TABLES: tuple[str, ...] = ("claude", "codex", "repo")`
        - `AGENTS: tuple[str, ...] = ("claude", "codex")`
        - `class Scope(StrEnum)`: `MACHINE = "machine"`, `REPO = "repo"`.
        - `class Layer(StrEnum)`: `PACKAGED = "packaged"`, `USER = "user"`,
          `REPO = "repo"`.
        - `class SourceError(AppException)` (from `rn_forge.commons.exceptions`).
          Raise it as
          `SourceError("{}: unknown top-level table {!r}; expected one of {}", path, key, ", ".join(TABLES))`.
        - `def user_overlay_path(rnf_home: Path) -> Path`, which returns
          `rnf_home / "share" / "agentkit" / "config.toml"`.
        - `def repo_overlay_path(repo_root: Path) -> Path`, which returns
          `repo_root / ".rn-forge" / "agentkit" / "config.toml"`.
        - `def load_packaged() -> dict[str, Any]`: reads each `AGENTS` file from
          `importlib.resources.files("rn_forge.agentkit").joinpath("defaults", f"{agent}.toml")`
          with `DocumentUtils.read`.
        - `def load_overlay(path: Path) -> dict[str, Any]`: calls
          `DocumentUtils.read(path, missing_ok=True)`, then raises `SourceError`
          for the first top-level key not in `TABLES`.
        - `def load_sources(scope: Scope, *, user_overlay: Path, repo_overlay: Path) -> MergeResult`:
          builds
          `[(Layer.PACKAGED, load_packaged()), (Layer.USER, load_overlay(user_overlay))]`,
          appends `(Layer.REPO, load_overlay(repo_overlay))` only when
          `scope is Scope.REPO`, and returns `DictUtils.merge_layers(*layers)`.
          Use `str(layer)` or the plain value as the layer name, so provenance
          values are the strings `"packaged"`, `"user"` and `"repo"`. Do not open
          or parse the repo overlay at machine scope.
        - A module docstring and a docstring on every public name (ruff `D` is on
          for `src/`; pyright is strict).
    - New `src/rn_forge/agentkit/defaults/claude.toml` and
      `src/rn_forge/agentkit/defaults/codex.toml`, each the single line
      `# Packaged <agent> defaults; keys at top level (F1.4 fills these).`, with
      `<agent>` replaced.
    - New `tests/test_sources.py` (below).
- **Leave alone:** `commands.py`, `main.py`, `product.py`, `cli.toml`, every
  file with a kiln "Generated by kiln" header, `pyproject.toml`, `uv.lock`,
  every doc page except this brief's `## Result`.

## Tests first

`tests/test_sources.py`. Use `tmp_path` and write overlay TOML with
`Path.write_text`. To control packaged defaults, monkeypatch
`rn_forge.agentkit.sources.load_packaged` to return a dict, except in the
packaged-files test. Before the change, each test fails with the
`ModuleNotFoundError` above. Shape: plain `def test_…` functions, as in
`tests/test_product.py`.

1. `test_s1_1_1_repo_layer_wins_with_provenance`: `effortLevel` set under
   `claude` in packaged (`"low"`), user (`"medium"`) and repo (`"high"`)
   layers, at `Scope.REPO`. Asserts
   `result.config["claude"]["effortLevel"] == "high"` and
   `result.provenance["claude.effortLevel"] == "repo"`.
1. `test_s1_1_1_user_list_replaces_packaged_list`: packaged
   `claude.permissions.deny = ["a", "b"]`, user `["c"]`. Asserts the merged
   list `== ["c"]` exactly, with provenance `user`.
1. `test_s1_1_1_nested_tables_merge`: packaged `{"claude": {"a": {"b": 1}}}`,
   user `[claude.a] c = 2`. Asserts
   `result.config["claude"]["a"] == {"b": 1, "c": 2}`, provenance of
   `claude.a.b` is `packaged`, and of `claude.a.c` is `user`.
1. `test_s1_1_1_absent_overlays_are_empty_layers`: neither overlay file exists,
   at `Scope.REPO`. Asserts the config equals the packaged dict and every
   provenance value is `packaged`.
1. `test_s1_1_1_unknown_top_level_table_fails_with_path_and_name`: user overlay
   holds `[cluade]\nx = 1\n`. `pytest.raises(SourceError)`; asserts
   `str(user_overlay)` and `"cluade"` are both in the exception's `.message`.
   Add a second case, parametrized or a separate assert, for a top-level
   scalar `foo = 1`, which also fails naming `foo`.
1. `test_s1_1_1_machine_scope_ignores_repo_overlay`: the repo overlay sets
   `[claude] effortLevel = "high"` and the user overlay `"medium"`, at
   `Scope.MACHINE`. Asserts the value is `"medium"` and no provenance value is
   `repo`. Then write the repo overlay as invalid TOML (`[claude`) and assert
   machine scope still loads without raising.
1. `test_s1_1_1_packaged_defaults_ship_for_each_agent`: no monkeypatch.
   `load_packaged()` returns a dict whose keys are exactly
   `{"claude", "codex"}` and each value is a dict. This proves the TOML files
   are packaged and readable as resources.
1. `test_s1_1_1_overlay_paths`:
   `user_overlay_path(Path("/h")) == Path("/h/share/agentkit/config.toml")`
   and
   `repo_overlay_path(Path("/r")) == Path("/r/.rn-forge/agentkit/config.toml")`.

## Out of scope

- Any CLI command, Typer wiring or `cli.toml` change (F1.3).
- Resolving the git root or `$RNF_HOME`. Callers pass paths in.
- Real default values in `defaults/*.toml` (F1.4).
- Validating keys inside a table (no schema in v1).
- List-append semantics (`append_paths`).
- Changes to rn-forge-commons.
