A runbook, `docs/runbooks/cutover-from-v0.md`, and the one-time steps it
scripts.

## Context

The old layout is `$RNF_HOME/agentkit/v<ver>/` plus `current` (v0.1.0 to
v0.5.0), not the tooling `versions/` layout. The old state is
`$RNF_HOME/share/agentkit/state.json`: flat, absolute-path keys, no schema
version.

Dead leftovers:

- `~/.claude/hooks/*.sh`: 5 files headed `# kiln:claude`, unreferenced.
- `~/.codex/hooks/*`: 2 dangling symlinks to a removed `rnforge-ai-config`.
- `~/.rn-forge/agentkit-rescue/`.

## S4.2.1 — Old-install detection and state archive

**State:** Closed (2026-11-21)

**Acceptance:**

- `doctor` detects an old-layout `$RNF_HOME/agentkit/v*/` and an old-format
  state file, and reports each with the runbook step that fixes it.

- `agentkit migrate-v0` renames the old state to `state.v0.json` and never
  deletes it; running it twice is a no-op. (Not `ToolProduct.migrate`: that
  runs between two installs of this product, and v0 used a different layout.)

- Contract: `agentkit.v0-install` (warning) cites runbook step 2,
  `agentkit.v0-state` (error: v1 reads that file as empty state) cites step 4.
  The runbook's steps are numbered 1 back up, 2 move the old install aside, 3
  install, 4 `migrate-v0`, 5 `apply --dry-run`, 6 `--force`, 7 trim, 8
  leftovers. `migrate-v0` refuses, changing nothing, when `state.v0.json`
  already exists beside a v0 `state.json`.

## S4.2.2 — Runbook

**State:** Closed (2026-11-21)

**Acceptance:**

- The runbook covers, in order: back up `~/.claude` and `~/.codex` config files;
  move the old install aside; install; `migrate-v0`; `apply --dry-run`;
  approve the adopted files with `--force`; trim body text duplicated by the
  new blocks (doctor clean); remove the dead leftovers listed above, each
  named.
- Each destructive step names its exact path and is marked "owner confirms".
- The owner runs it on this machine; outcome line on the story: doctor exit 0
  and `apply` reports all unchanged. (Not scriptable: listed under the
  feature's acceptance.)

Outcome: run on this machine 2026-11-21: `agentkit doctor` exit 0,
`agentkit apply` all 18 artifacts `unchanged`; the run fixed the runbook's loop
variable (`path` to `rel`) and its step 8 shebang check.

## Acceptance

```bash
set -euo pipefail

task test -- tests/test_migrate_v0.py   # S4.2.1: detection, archive, idempotent

f=docs/runbooks/cutover-from-v0.md
rg -q -U -i '(?s)back up.*move.*install.*migrate-v0.*--dry-run.*--force.*doctor.*leftovers' "$f"   # S4.2.2: steps in order
rg -q 'owner confirms' "$f"                                                                         # S4.2.2: destructive steps marked
rg -q '\.rn-forge/agentkit-rescue' "$f"                                                             # S4.2.2: each leftover named
```

Not scriptable:

- S4.2.2: the owner runs the runbook on this machine and records the outcome
  line on the story: `doctor` exits 0 and `apply` reports every artifact
  `unchanged`.
