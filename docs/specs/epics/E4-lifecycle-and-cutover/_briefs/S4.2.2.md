# S4.2.2 — Runbook

Brief for [S4.2.2](../F4.2-machine-cutover.md#s422-runbook), at the commit that

## Goal

Write `docs/runbooks/cutover-from-v0.md`: the owner's procedure for moving this
machine from agentkit v0 to v1. The owner runs it afterwards. That run is not
part of this story's build.

## Settled

- **Shape.** Follow
  [docs/runbooks/\_structure.md](../../../../runbooks/_structure.md) and the
  style of
  [recovering-from-drift.md](../../../../runbooks/recovering-from-drift.md): an
  H1, a short paragraph saying when to use it, then numbered `## N. <step>`
  sections with fenced `bash` blocks. Each step says what evidence shows it
  worked. Every destructive step (`mv`, `rm`, `--force`, or an edit of a
  file's body) carries the bold line `**Owner confirms** before running.` and
  names each exact path it touches.

- **Steps, in this order and with these numbers.** The numbers are already cited
  by `doctor`'s findings (`agentkit.v0-install` cites step 2,
  `agentkit.v0-state` step 4), so they are fixed:

    1. **Back up.** Copy, with `cp -a`, into
       `~/.rn-forge/backup/cutover-v0-$(date +%Y%m%d)/`: `~/.claude/CLAUDE.md`,
       `~/.claude/settings.json`, `~/.claude/output-styles/`,
       `~/.claude/skills/`, `~/.claude/hooks/`, `~/.codex/AGENTS.md`,
       `~/.codex/config.toml`, `~/.codex/hooks.json`, `~/.codex/hooks/`,
       `~/.codex/skills/` and `~/.rn-forge/share/agentkit/`. Evidence: `ls` of
       the backup dir.
    1. **Move the old install aside.**
       `mv ~/.rn-forge/agentkit ~/.rn-forge/agentkit-v0` and
       `rm ~/.rn-forge/bin/agentkit`, the symlink into
       `../agentkit/current/bin/agentkit`. Owner confirms.
    1. **Install.** From this repository's checkout, run `task build`, then
       install the built archive with the lifecycle verb's `--archive` option.
       Read `rn_forge.tooling`'s install code in `.venv` to find which archive
       `--archive` takes (wheel or sdist) and the exact
       `dist/agentkit-<version>...` name pattern, and write that exact command.
       Before the first install, the console script is `.venv/bin/agentkit`.
       Evidence: `agentkit --version` from `~/.rn-forge/bin`.
    1. **`agentkit migrate-v0`.** It renames
       `~/.rn-forge/share/agentkit/state.json` to `state.v0.json`, never deletes
       it, and a second run prints `nothing to migrate`. Evidence:
       `agentkit doctor` no longer reports `agentkit.v0-state`.
    1. **`agentkit apply --dry-run`.** Read the rows. `insert` and `create` are
       expected. A `conflict` row is a file v0 wrote that v1 has no state for:
       the live hook scripts under `~/.rn-forge/share/agentkit/`,
       `~/.claude/output-styles/concise.md`, the skill files, and
       `~/.codex/hooks.json`. Show each with `agentkit diff`.
    1. **Approve the adopted files with `--force`.** Run
       `agentkit apply --force <path> ...`, naming each conflict path from step
       5 relative to `$HOME`. Owner confirms after reading each diff.
       `~/.codex/hooks.json` must show no diff: v1 renders it byte-identical
       when `RNF_HOME` is unset. If it differs, stop, because Codex's hook trust
       would reset. Evidence: a second `agentkit apply` reports every row
       `unchanged` or `skip`.
    1. **Trim body text the new blocks duplicate.** Run `agentkit doctor` and
       `agentkit plan`. For each `agentkit.heading-duplicated` warning, delete
       that section from the file's body, outside the `rn-forge agentkit`
       markers. Never edit inside the markers. Owner confirms each edit.
       Evidence: `agentkit doctor` exits 0, with no `agentkit.*` warnings about
       instruction files.
    1. **Remove the dead leftovers.** Owner confirms each `rm`:
        - `~/.claude/hooks/*.sh`: the five v0 scripts headed `# kiln:claude`
          (`post-edit-git-stage.sh`, `pre-bash-guard.sh`, `pre-write-protect.sh`,
          `session-compact-context.sh` and `user-prompt-secret-guard.sh`). Check
          each one's header with `head -1` first, and check that
          `~/.claude/settings.json` no longer references `~/.claude/hooks/`.
        - `~/.codex/hooks/*`: two dangling symlinks into a removed
          `rnforge-ai-config` (`pre-bash-guard.sh` and
          `user-prompt-secret-guard.sh`). Check with `ls -l` that they dangle.
        - `~/.rn-forge/agentkit-rescue/`.
        - `~/.rn-forge/agentkit-v0/`, once v1 has run cleanly for a while.

- **Closing section** `## Done when`: `agentkit doctor` exits 0, and
  `agentkit apply` reports every artifact `unchanged` (or `skip` for seeds).
  The owner records that outcome on S4.2.2.

- **Rollback section** `## Rolling back`: restore the step 1 backup with
  `cp -a`, move `agentkit-v0` back, and re-create the `bin/agentkit` symlink.
  Owner confirms.

## Tests first

None in pytest. F4.2's acceptance block is the check. Run these three read-only
`rg` checks as plain shell, before writing (each exits non-zero) and after (each
exits 0):

```bash
f=docs/runbooks/cutover-from-v0.md
rg -q -U -i '(?s)back up.*move.*install.*migrate-v0.*--dry-run.*--force.*doctor.*leftovers' "$f"
rg -q 'owner confirms' "$f"
rg -q '\.rn-forge/agentkit-rescue' "$f"
```

Note that the second check is case-sensitive: the literal lowercase phrase
`owner confirms` must appear at least once, so include it in the intro sentence
(for example, "Each step marked owner confirms ...").
